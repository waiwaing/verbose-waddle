PhotoSwipe 5.4.4: removing the current slide

Removes the current item from pswp.options.dataSource, then calls refreshSlideContent for the previous, current and next indexes, as the docs suggest.

  1. Open the gallery. It opens on A, and PhotoSwipe preloads B and C (preload: [1, 2]).
  2. Click Remove current. A is removed and B is shown. The items are now B, C, D, E, F.
  3. Press → twice. The second press should show D, but it shows C again: the content cached for index 2 is still the old item at that index. D is never shown.

The label at the bottom compares what's rendered (currSlide.content.data) with the item at the current index (currSlide.data), and goes red when they differ.
